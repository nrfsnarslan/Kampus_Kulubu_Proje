# Müzik Kulübü — Kampüs Web Sitesi

Bu proje, BPR201 Haftalık Proje Ödevi 1'de belirtilen temel kapsam dikkate alınarak hazırlanmış, HTML, CSS ve JavaScript kullanan üç sayfalı bir kampüs kulübü sitesidir.

## Dosyalar
- `index.html` — Ana sayfa, kulüp tanıtımı ve yaklaşan etkinliklerden örnekler.
- `etkinlikler.html` — Beş özgün etkinlik kartı; başlık, tarih, yer ve açıklama; tarayıcı içinde çalışan arama ve kategori filtreleri.
- `hakkimizda.html` — Kulübün amacı, hikâyesi, değerleri ve katılım çağrısı.
- `style.css` — Üç sayfanın ortak tasarımı ve mobil uyumluluk.
- `script.js` — Mobil menü, etkinlik araması ve kategori filtreleri.

## Çalıştırma
`index.html` dosyasını tarayıcıda açman yeterlidir. Arama ve filtreler için sunucu, veritabanı veya API gerekmez. Yazı tipleri çevrim içi yüklenir; internet bağlantısı yoksa sistem yazı tipleri kullanılır.

## Teslimden önce
1. ZIP içindeki ana klasörün adını öğretmenin istediği biçime göre `ÖĞRENCİNO_AD_SOYAD` olarak değiştir.
2. Bu klasörün içinde HTML, CSS, JS ve README dosyalarının doğrudan bulunduğunu kontrol et.
3. Öğrenci numaranı, adını ve soyadını teslim dosyasının klasör adına yaz.
4. Etkinlik tarihleri örnek plan olarak kullanılmıştır. Gerçek kulüp takviminiz varsa tarih, saat ve yerleri güncelle.
5. Siteyi kendi bilgisayarında/Codespaces üzerinde açıp bağlantıları, mobil menüyü, arama ve filtreleri test et. Kodu anlayarak kişiselleştir; ödev yönergesi GitHub Codespaces ve GitHub Copilot desteğiyle çalışma, kod inceleme ve test sürecini de bekliyor.
